\section{项目经历}

\subsection{神券包售卖算法定价策略提效}[2024 年 5 月~--~2026 年 3 月]

\begin{itemize}
  \itemsep 0.4em
  \item 深度参与美团神券包的算法定价策略，负责下沉市场整体业务，带领 3 人团队完成从人工规则到算法策略的全面升级，覆盖 Uplift 建模、预算分配与成本调控全链路。
  \item 针对实付 GTV 长尾噪声高、信噪比低的问题，设计目标分解（$\text{GTV} = \text{订单} \times \text{客单价}$）与凹函数变换方案以提升建模信噪比，并引入端到端 DFL 替代两阶段 ML+OR 框架，后续采用 MMoE 多目标建模实现跨业务线的差异化策略，并针对高维定价动作空间通过动作聚合与启发式剪枝策略压缩决策空间。
  \item 多轮策略迭代均获推全，CLC 与下沉大盘订单量与实付 GTV 持续取得显著正向收益。
\end{itemize}

\subsection{基于 MPC 的预算平滑托管系统}[2025 年 12 月~--~至今]

\begin{itemize}
  \itemsep 0.4em
  \item 针对各业务预算分配依赖运营经验、流量突变时易超花/少花进而被动调整补贴力度损伤算法效率的问题，带领 5 人团队从零搭建基于 MPC 的预算平滑托管系统，覆盖技术方案设计、流量预估模块开发与多策略整合全链路工作。
  \item 将总预算拆解为「用券订单量 $\times$ 单均券成本」，以 Prophet 为基础构建时序预测中台，估算每日流量并按比例生成基线分配序列；引入基于周内增量 ROI 差异的启发式乘性微调，实现跨时段预算结构性优化；同步建立前置沟通机制，实时掌握预算变动节奏，将策略从被动响应转向主动前置。
  \item 方案上线后实验期间做功行业补贴率完全对齐，订单与实付均取得显著正向收益，验证了模型驱动操盘的可行性，目前该方案正在逐步落地推广。
\end{itemize}

\subsection{端到端自动化时序预测系统}[2023 年 7 月]

\begin{itemize}
  \itemsep 0.4em
  \item 设计并实现面向业务预测场景的端到端自动化时序预测系统，对 ATTILA 的客户进行聚类细分，自动完成客户数量、订单量及收入等多指标的预测与评估。
  \item 系统性研究分解集成策略对计量经济学与深度学习方法的影响规律，构建统一评估框架，在时序长度、粒度、季节性与平稳性等多维特征下量化 ARIMA、Theta、ES-RNN、Prophet、Transformer 等模型的适用边界。
  \item 基于评估结论实现自动策略与模型选择，根据数据特征自动匹配最优预测策略（集成/分解集成）与模型组合；以 Flask + Plotly 封装为 Web 应用，支持非技术用户通过 Excel 上传完成全流程预测，提供多维可视化看板，以支持业务决策。
\end{itemize}

% \vspace{-\parskip}

\subsection{Rankformer \& STLformer: 面向非线性依赖的时序 Transformer 预测框架}[2023 年 3 月]

\begin{itemize}
  \itemsep 0.4em
  \item 提出 Rankformer，针对传统点积注意力无法建模非线性依赖的问题，基于 ARCH 效应检验识别序列异方差性，以 Spearman 相关系数替代点积注意力，实现对序列非线性依赖的显式建模。
  \item 在此基础上提出 STLformer，引入 STL 滚动分解将序列分离为趋势与季节性成分，分别由编、解码器建模，进一步提升对复杂时序模式的捕捉能力。
  \item 模型实现 $\mathcal{O}(N \log{N})$ 预测复杂度，在多个公开数据集上取得 SOTA 精度，在具有非线性依赖特征的金融时序上相对基线提升 +21\%。
\end{itemize}
